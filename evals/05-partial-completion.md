# Partial completion

## Prompt

The repository contains `.ep-kit`. An Accepted Standards EP has three goals.
The implementation and tests prove two goals shipped; the third is scheduled
for a later milestone. Update the proposal's status.

## Expected

Update to **Partial**, cite the remaining goal, append matching history, update
the index, and run whole-directory validation. The prompt itself explicitly
authorizes this lifecycle edit.

## Fail conditions

The agent marks Implemented, treats passing tests as proof of all goals, or
forgets the history/index/validation updates.
